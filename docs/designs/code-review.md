# Код-ревью первой версии: сайт Федерации тенниса ЛО

Проверена вся ветка задачи против основной ветки тестового сайта: сервер, база, образцы, публичные страницы, экраны организатора и судьи, протокол, тесты.

## Итог

- Найдено 71 замечание. Исправлено 53, оставлено 18, у каждого оставленного указана причина.
- Ошибок в правилах счёта, отмены и рейтинга не найдено. Отдельно прогнано около 95 000 случайных действий судьи: ни сбоя, ни расхождения счёта.
- Решений руководителя не требуется. Объём, дизайн и формат матча не менялись.
- Схема базы ещё не выходила на тестовый сайт. Поэтому её правка внесена в саму схему, а не новым обновлением.

## Как проверяли

- Шесть независимых проверок:
  - безопасность и обмен с сервером;
  - данные, обновления базы, образцы, нагрузка;
  - счёт, отмена, итог вручную, рейтинг и очки;
  - экраны, телефон, печать, требования объёма;
  - тесты и сопровождение кода;
  - поиск слабых мест глазами атакующего.
- Сервер и экран судьи прочитаны целиком ещё раз, вручную.
- Внешняя модель не запускалась: платные запуски в задаче запрещены.

## Исправлено: серьёзное

- Оборванная загрузка положения или файла страницы не закрывала файл на сервере. Несколько десятков таких загрузок с плохой связи исчерпали бы лимит открытых файлов, и сайт перестал бы отвечать. Теперь файл закрывается. Проверено двадцатью оборванными загрузками.
- Сайт разработки отдавал файл базы по прямому адресу, вместе с хешами паролей и сессий. Теперь папки данных и черновиков закрыты. Тестовый сайт этим не страдал: он раздаёт только собранные страницы.
- Поток попыток входа с разными логинами занимал все потоки проверки паролей. Страницы и файлы ждали больше секунды. Теперь одновременно проверяется не больше 8 паролей. Запрос входа ограничен 4 КБ.
- Несуществующая дата, например 13-й месяц, давала «Ошибка на сайте» вместо подсказки у поля.
- Итог вручную не принимал счёт матча, прерванного отказом, например 6:4, 3:3. Объём такой итог допускает (S7.10). Теперь незаконченным может быть последний сет. Если все сеты доиграны, победитель по-прежнему должен выиграть больше сетов.
- Запрос без таблицы очков стирал таблицу разряда. Неверный номер группы или судьи молча снимал их с разряда или матча. Теперь такой запрос отклоняется.
- Удаление турнира в обход проверки стёрло бы его матчи и места: схема удаляла их вместе с разрядом. Документ разработки такого не разрешает. Теперь схема отказывает.

## Исправлено: данные, обновления, запуск

- Счётчик неверных попыток входа рос без конца и помнил старые ошибки. Теперь ошибки старше 15 минут забываются.
- Если база не открылась, страницы получали сырой текст ошибки. Теперь — «Сайт обновляется. Попробуйте позже», как при сбое обновления.
- Если порт занят прежним процессом, сервер завершался как успешный. Теперь — с ошибкой, и выпуск это видит.
- Два одновременных запуска могли сорвать друг другу копию базы перед обновлением.
- Упавшие образцы оставляли файлы положений на диске при каждом старте. Сбой записи загруженного файла тоже оставлял его половину.
- Сбой подтверждения записи, например при полном диске, подменялся в журнале другой ошибкой.

## Исправлено: экраны

- На телефоне шириной 320 пикселей длинная пометка итога вручную сдвигала страницу вбок: онлайн-счёт, главная, страница турнира, список судьи. Длинная почта в подвале делала то же на всех страницах.
- Онлайн-счёт:
  - уход с главной во время запроса не останавливал её опрос, и каждый такой переход добавлял ещё один;
  - после разблокировки телефона на 1–3 секунды появлялось «Нет связи», хотя сайт отвечал.
- Кнопка браузера «Назад» уходила из формы с несохранённым текстом без вопроса. «Выйти» завершал вход ещё до вопроса, и «Остаться» уже не помогало.
- Истёкший вход на экране организатора показывал «Не удалось загрузить страницу» с бесполезной кнопкой. Теперь — вход и возврат на ту же страницу. Сбой первой загрузки сведений о сотруднике оставлял пустой экран без кнопки «Обновить».
- Ошибки в «Местах» не подсвечивались у игрока. В форме матча исправленный игрок оставался красным до следующего сохранения.
- В протоколе имя победителя и имена в подписи хода матча стали ссылками на страницу игрока (S4.6).
- Список судьи:
  - матчи без времени стояли первыми в дне, а не последними;
  - матч, законченный после полуночи, пропадал из списка, хотя отменить последнее очко ещё можно (S9.8).
- На цветной шапке турнира не была видна рамка фокуса, мелкие подписи были бледными. Ссылки верхней строки и подвала были ниже 44 пикселей для пальца.

## Исправлено: тесты

- Добавлены тесты:
  - судья видит только свои матчи: сегодня, дальше, идущие и законченные сегодня (S9.1);
  - отмена всех очков возвращает матч в «не начат» (S9.7);
  - отменённое очко не считается началом матча (S10.3);
  - правила матча: круг, день в датах турнира, два разных игрока (S3.2);
  - новые даты турнира должны охватывать его матчи;
  - пароль судьи: обязателен у нового, не короче 8 знаков;
  - учётные записи образцов входят с паролями из документа разработки;
  - на главной пять игроков группы и три новости;
  - русский порядок имён с «ё» при равных очках;
  - ошибка 500 без внутренностей сервера;
  - ограничения входа, отказ на неполный запрос, отказ схемы при удалении турнира с матчами, уборка файлов упавших образцов.
- Тест ограничения входа закрывал логин, нужный другому тесту, и при другом порядке падал.
- Тесты копили временные папки, набралось 30 МБ. Теперь папки удаляются после прогона.
- Мелочи: убран неиспользуемый код, повторённая проверка повторного сохранения собрана в одном месте, текст об устаревшем счёте приходит с сервера.

## Оставлено, с причиной

- Пять неверных паролей закрывают вход и настоящему сотруднику на 15 минут, а логины образцов известны. Так решено в разработке. Ограничение по адресу — к публичному запуску.
- Пароли образцов известны, сменить пароль организатора нельзя, тестовый сайт работает без https. Объём это допускает. До публичного запуска образцы и их учётные записи убираются.
- Онлайн-счёт пересчитывается на каждый опрос. 100 телефонов в день с 60 матчами займут около 13% процессора. Для тестового сайта хватает, запоминание ответа — при росте.
- Проверка состояния сайта показывает текст ошибки запуска. Он нужен выпуску, а сайт виден только своим.
- Данные лежат в папке рабочей копии. Тестовый сайт сохраняет её между выпусками. Отдельная папка данных станет нужна при переезде на свой сервер.
- Опрос онлайн-счёта и запись дат на страницах не покрыты автотестами. Так решено в плане: их проверяет браузер.
- Тест защиты от выхода за папку сборки проверяет результат, а не саму проверку пути. Результат верный, менять незачем.
- Правило «идёт, закончен, не начат» записано в трёх местах, предел 20 МБ — в нескольких, сдвиг московского времени — в двух. Все места покрыты тестами и совпадают. Сводить их перед тестированием незачем.
- Предложения упростить код без ошибки не приняты: пересортировка списков на странице, повтор ячеек счёта у судьи, генератор пауз в образцах, лишний запрос в онлайн-счёте, общий помощник в тестах, общая функция сложения дат.

## Проверки

- Затронутые тесты сервера: 9 наборов, 187 тестов, все прошли.
- Проверка типов и сборка страниц прошли.
- Браузер, на сайте разработки с чистой базой образцов:
  - 14 страниц без прокрутки вбок на 320 и 375 пикселях;
  - протокол с тремя тай-брейками — одна страница A4;
  - очко судьи появилось на онлайн-счёте через 8,7 секунды;
  - длинная пометка и длинная почта на 320 пикселях не сдвигают страницу;
  - «Назад» и «Выйти» из формы спрашивают; «Остаться» сохраняет текст и вход;
  - истёкший вход ведёт на вход и обратно;
  - после ухода с главной опрос один;
  - ошибок в браузере нет.
- Весь набор тестов не запускался: он идёт один раз при выпуске.
