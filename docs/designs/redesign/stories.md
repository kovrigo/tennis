# Истории: новый облик сайта

Бриф: бриф нового облика сайта.

Роли: посетитель (игрок, родитель, тренер, болельщик; без регистрации), организатор (сотрудник федерации), судья (судья на вышке).

## Истории

- **S1.** Как посетитель, я хочу с первого взгляда узнавать лигу разряда или группы рейтинга, чтобы быстро найти своих: мужчин, женщин, юношей или девушек.
  - Используются только фотографии, присланные заказчиком.
  - Название без лиги остаётся без фотографии.
- **S2.** Как посетитель, я хочу легко читать текст, лежащий на фотографии, чтобы не терять сведения о турнире и группе ради картинки.
  - Фотография видна сквозь подложку.
  - Подложка одного тёмно-синего оттенка на всех страницах.
- **S3.** Как посетитель, я хочу видеть рейтинг в одном виде на главной, на странице рейтинга и в итогах турнира, чтобы сразу понимать место игрока.
- **S4.** Как посетитель, я хочу так же удобно смотреть сайт с телефона, чтобы следить за турнирами с корта.
  - Без горизонтальной прокрутки на ширине от 320 пикселей.
- **S5.** Как посетитель, я хочу находить на сайте всё на прежних местах, чтобы новый облик не мешал привычной работе.
  - Страницы, тексты, порядок блоков и поведение не меняются.
- **S6.** Как организатор, я хочу вносить данные так же, как раньше, чтобы новый облик не прерывал работу федерации.
- **S7.** Как судья, я хочу вести счёт так же, как раньше, чтобы новый облик не мешал матчу.

## Покрытие

Для каждого результата — история, которая покрывает его для каждой роли. «нет» — роли это не нужно.

- Лига видна с первого взгляда
  - Посетитель: S1
  - Организатор: нет
  - Судья: нет
- Текст на фотографии читается
  - Посетитель: S2
  - Организатор: нет
  - Судья: нет
- Рейтинг в одном виде
  - Посетитель: S3
  - Организатор: нет (на экранах организатора рейтинга нет)
  - Судья: нет
- Удобно с телефона
  - Посетитель: S4
  - Организатор: нет
  - Судья: S7
- Всё на прежних местах
  - Посетитель: S5
  - Организатор: S6
  - Судья: S7
