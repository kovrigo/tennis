# План: три исправления нового облика

Бриф: `docs/designs/redesign/visual-redesign.md`, раздел «Исправления до проверки». Истории: `docs/designs/redesign/stories.md`.

Облик одобрен заказчиком. План делает только три исправления и их автотесты. Сервер, база и API не меняются.

## Что уже есть

- `leagueOf` в `src/components/League.tsx` выбирает лигу по названию. Его зовут главная (через `firstLeague`), рейтинг, итоги турнира и карточка игрока. Правка в одном месте чинит все четыре страницы.
- Рейтинг, главная и карточка игрока красят полосу по номеру места: `place <= 3 ? m${place}`. Это верно, не трогаем.
- Итоги турнира красят по порядку строки: `src/pages/public/Tournament.tsx:157` (таблица очков) и `:185` (список мест без таблицы).
- Классы `m1`, `m2`, `m3` уже дают цвет полосы в `src/styles/public.css:290-308`. Новых стилей для полосы не нужно.
- Подпись места приходит с сервера как есть: `rows[].name` в таблице очков, `places[].place` в списке. Список отсортирован по алфавиту на сервере (`server/views/public.ts:113`), порядок не меняем.
- Автотесты: vitest, только `server/**/*.test.ts` (`vitest.config.ts`).

## Задачи

1. **Лига по названию.** `leagueOf` проверяет слова в порядке Брифа:
   - «женщ», «женск» — женщина;
   - «мужч», «мужск» — мужчина;
   - «девуш», «девоч», «юниорк» — девушка;
   - «юнош», «мальч», «юниор», «дет», «до N лет» — юноша;
   - иначе лиги нет.

   Комментарий над функцией переписать целиком: пол теперь решает раньше возраста, примеры названий новые. Файл: `src/components/League.tsx`.
2. **Место по подписи.** Новый файл `src/place.ts`:
   - `placeOf(label)` — номер места или `null`, по правилу Брифа, пункт 2;
   - `placeClass(label, marked)` — « m1», « m2», « m3» для первых трёх мест, иначе пустая строка. Без отмеченных игроков всегда пустая строка.

   `Tournament.tsx`: строка таблицы очков берёт `placeClass(row.name, row.players.length > 0)`. Решает каждая строка сама, а не разряд целиком: при отмеченном только третьем месте строка победителя серая. Строка списка мест берёт `placeClass(p.place, true)`: в списке только места с игроками.
3. **Цифра места темнее.** `src/styles/public.css:345-360`: `#c27c00` → `#9a6700`, `#d4580a` → `#b84a08`, `#7a889e` → `#66748a`. Цвета полосы не меняются.
4. **Автотесты.** Пишутся вместе с задачами 1 и 2. В `vitest.config.ts` добавить `src/**/*.test.ts`. Тесты:
   - `src/components/League.test.ts` — каждое название из критериев Брифа и оба названия с двумя лигами из «Известные ограничения»;
   - `src/place.test.ts` — каждая подпись из критериев Брифа, плюс «2», «2-е место», «3-4 место», «Место 3–4», «3—4», «3 – 4 место», регистр и лишние пробелы, пустая подпись, «0»;
   - там же `placeClass` без отмеченных игроков: пустая строка при любой подписи.

## Разбор подписи места

```
подпись ─► обрезать края, нижний регистр, пробелы в один
            │
            ├─ целиком слово из списка? ─► 1 / 2 / 3
            │    победитель, финалист, полуфинал, полуфиналист, 1/2 финала,
            │    первое место, второе место, третье место
            │
            ├─ целиком «[место] N[-е] [тире M] [место]»? ─► N
            │    тире: дефис, короткое, длинное или минус, пробелы вокруг можно
            │
            └─ иначе ─► нет места
                         │
номер 1–3 ─► m1 / m2 / m3 ◄──┘ нет места, 0 или 4+ ─► серая строка
```

Таблица очков: строка без игроков серая при любой подписи. Решает сама строка. Список мест без таблицы: в нём только места с игроками.

## Проверка плана

### Устройство

- Новый модуль один, `src/place.ts`, без зависимостей. Его зовёт только `Tournament.tsx`.
- Сбой в работе: организатор напишет подпись, которой нет в правиле, например «Победительница». Строка выйдет серой, ложного победителя нет. Так задумано Брифом, раздел «Состояния».
- Рейтинг, главную и карточку игрока на `placeClass` не переводим. Они красят по числу, а не по подписи, и работают верно. Перевод расширил бы правку без пользы.

### Качество кода

- Правило подписи живёт в одном месте и обслуживает и таблицу, и список. Повтора нет.
- `placeClass` повторяет выражение `m${place}` из трёх страниц рейтинга. Общий помощник для них не делаем: те страницы вне исправлений.

### Тесты

Компонентных тестов в проекте нет, библиотеки для них нет. Новую библиотеку не ставим. Правило строки целиком в `placeClass`, поэтому тест его держит. В `Tournament.tsx` остаётся только вызов.

Браузер, база задачи. Образцы `server/seeds/001_samples.ts` дают таблицу очков с «Победитель» и список без таблицы с «1 место» и «2 место». Разряда без мест и разряда только с третьим местом в образцах нет. Их делаем правкой базы задачи на время проверки и после проверки возвращаем.

### Скорость

Разбор подписи — два сравнения на строку. Страница итогов держит десятки строк. Замечаний нет.

### Сбои

- Подпись с опечаткой: серая строка, тест «без места» это держит. Тихий сбой допустим: цвет не единственный знак, подпись видна текстом.
- Картинки лиг в тесте: `League.tsx` подключает файлы `.webp`. vitest разбирает их как адреса файлов, отдельная настройка не нужна. Проверить первым запуском теста.
- Критических пробелов нет.

### Вне плана

- Перевод рейтинга, главной и карточки игрока на общий помощник места: они работают верно.
- Тесты отрисовки страниц: нужна новая библиотека.
- Правка порядка мест в списке без таблицы: Бриф требует прежний порядок.

### Порядок работы

Одна линия: настройка тестов, затем лига с тестом, место с тестом, цвет цифры, проверка в браузере. Правки мелкие, параллельная работа не окупится.

### Второй взгляд

Платную проверку другой моделью не запускали: платные запуски задачи исчерпаны. Независимый проверяющий той же модели прочёл план и код. Его находки вошли в план:

- серая строка решается по каждой строке, а не по разряду;
- правило строки перенесено в `placeClass`, чтобы тест его держал;
- в образцах нет разряда без мест и разряда только с третьим местом, их делает проверка;
- тире в диапазоне: дефис, короткое, длинное, минус, с пробелами;
- комментарий над `leagueOf` переписывается целиком;
- тесты пишутся вместе с кодом.

Он подтвердил: картинки `.webp` открываются в тестах без настройки; по порядку строки красят только две строки `Tournament.tsx`; новые цвета цифры дают от 4,57 до 5,22 к 1.

Нерешённых вопросов нет.
