## Роли

- Посетитель: читает всё публичное, открывает и печатает протоколы. Без входа ничего не меняет.
- Судья: ведёт счёт только назначенных ему матчей. Видит свои матчи сегодня и в следующие дни, а также свой незаконченный матч прошлых дней.
- Организатор: вносит и правит турниры, разряды, таблицы очков, места, матчи, игроков, судей, новости, группы и контакты.

## Публичные страницы

- `/` — главная: три ближайших турнира, идущие матчи, три последние новости, первые пять игроков каждой группы.
- `/tournaments` — календарь: идут, предстоящие, завершённые.
- `/tournaments/<номер>` — турнир: сведения, положение, разряды, таблицы очков, матчи, места.
- `/live` — онлайн-счёт: матчи на сегодня и все идущие.
- `/matches/<номер>` — протокол матча.
- `/rating` — рейтинг по группам.
- `/players/<номер>` — игрок: турниры, места, очки.
- `/news`, `/news/<номер>` — новости.
- `/login` — вход для сотрудников.

## Страницы сотрудников

- `/judge` — «Мои матчи» судьи. `/judge/matches/<номер>` — счёт матча.
- `/admin/tournaments` — турниры организатора, с разрядами, местами и матчами внутри.
- `/admin/players`, `/admin/judges`, `/admin/news`, `/admin/groups`, `/admin/contacts` — игроки, судьи, новости, рейтинговые группы, контакты.

## Счёт

- Только одиночные матчи.
- Матч до двух выигранных сетов. Сет до шести геймов с разницей в два.
- При 6:6 тай-брейк до семи очков с разницей в два, в каждом сете, включая третий.
- Гейм с «больше-меньше».
- Матч другого формата судья не ведёт. Его итог вносит организатор вручную.
- Сет с тай-брейком в протоколе: 7:6(5). В скобках очки проигравшего тай-брейк.

## Онлайн-счёт

- Страница сама запрашивает счёт каждые 10 секунд. Очко видно не позже чем через 15 секунд.
- Нет ответа дольше 30 секунд — «Нет связи с сайтом» и время последнего обновления.

## Рейтинг

- Сумма очков игрока по разрядам группы за всё время, без сезонов.
- Равная сумма — общее место, игроки по алфавиту. Следующее место пропускается: 1, 2, 2, 4.
- Игроки без очков в рейтинг не входят.
- Разряд без таблицы очков очков не даёт. Игрок без места получает 0.

## Вход

- Пять неверных паролей подряд закрывают логин на 15 минут.
- Вход держится 24 часа после последнего действия.
- Новый пароль судьи завершает все его входы.

## Об игроке

Публикуются только имя, фамилия и город.

## Положение

PDF или Word, до 20 МБ. Таблицу очков без положения сохранить нельзя.

## Проверка состояния

`GET /api/health` отвечает:

- `commit` — выпущенный коммит;
- `migration` — последнее обновление базы (`latest`) и сколько ждут (`pending`);
- `seed` — последние образцы и сколько ждут.

Ответ 503 и поле `error` — обновление базы или образцы не применились.

## Команды разработчика

- `bun install` — зависимости.
- `paneweb up` — сайт разработки.
- `bun run test` — тесты сервера. Только затронутые файлы: `bun run test server/score.test.ts`.
- `bun run build` — проверка типов и сборка.
